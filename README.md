# جداولي (Kotlin) — المرحلة 1

نسخة أندرويد أصلية (Kotlin + Jetpack Compose + Room) من تطبيق جداولي.

## ما فيه الآن
- قاعدة بيانات Room: الجداول والخلايا والملاحظات بنفس بنية جداولي القديم.
- **استيراد النسخة الاحتياطية** القديمة (zip مشفّر AES-256 أو JSON): إضافة أو استبدال.
- شاشة البيانات: اختيار الجدول، عرض الشبكة، تعديل الخلايا (صح/خطأ، قوائم بألوانها، أرقام، نصوص).
- معرّف التطبيق `com.jadawli.kt` فيُثبَّت بجانب جداولي القديم دون تعارض.

## الرفع والبناء
1. أنشئ مستودعاً جديداً، وأضف يدوياً الملف `.github/workflows/build-apk.yml` (مرة واحدة).
2. ارفع ملف المشروع المضغوط إلى مجلد `incoming/` فيُستخرج ويُبنى تلقائياً.
3. نزّل الـ APK من Actions ← Artifacts.
(التوقيع بمفتاحك يحتاج الأسرار نفسها: KEYSTORE_BASE64 و KEYSTORE_PASSWORD و KEY_ALIAS و KEY_PASSWORD.)
